## Enemy Reserve Bench

Gegner können aus Spielfeld, Akteursliste oder Actor-Kompendien auf die Reserve gelegt werden. Ein Reserve-Eintrag kann später an einem vorhandenen Spawnpunkt eingesetzt werden. Der Eintrag bleibt nach dem Spawn auf der Bench und kann erneut verwendet werden.

Nicht zum aktuellen Grundkern gehörender Altcode bleibt unter `legacy-disabled/` deaktiviert.

## Updates
